# Laboratorio Día 2: Permisos

## Objetivo
Aprender a visualizar, interpretar y modificar los permisos de archivos y directorios en Linux, comprendiendo el significado de lectura, escritura y ejecución para usuarios, grupos y otros.

## Comandos utilizados
- `ls -l` → Mostrar permisos de archivos y directorios.
- `chmod` → Cambiar permisos.
- `chown` → Cambiar propietario.
- `chgrp` → Cambiar grupo.

## Ejemplo práctico
1. Crear un archivo y verificar sus permisos iniciales.
2. Modificar permisos con `chmod` para permitir ejecución.
3. Cambiar propietario con `chown` y grupo con `chgrp`.

## Conclusión
El control de permisos es esencial para la seguridad y administración del sistema, permitiendo definir quién puede acceder o modificar los recursos.
